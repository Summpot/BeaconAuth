## Docker 사용 (권장)

```bash
# 최신 이미지 받기
docker pull ghcr.io/summpot/beacon_auth:latest

# 서버 실행
docker run -d --name beaconauth \
  -p 8080:8080 \
  -v $(pwd)/data:/app/data \
  -e DATABASE_URL=sqlite:///app/data/beacon_auth.db \
  ghcr.io/summpot/beacon_auth:latest
```

서버는 `http://localhost:8080` 에서 접근할 수 있습니다.

## 사전 빌드 바이너리 사용

공식 프로젝트 릴리스 페이지에서 운영체제와 CPU에 맞는 서버 아카이브를 다운로드한 뒤 로컬에서 압축을 해제하세요.

**Linux / macOS**:

```bash
tar -xzf beaconauth-<platform>.tar.gz
chmod +x beacon
./beacon serve
```

**Windows (amd64)**:

```powershell
# zip 파일 다운로드 및 압축 해제
# PowerShell에서 실행:
.\beacon.exe serve
```

## 소스에서 빌드

### 준비물

- Rust (stable)
- Node.js (LTS)
- pnpm

### 빌드 단계

```bash
# 저장소 클론
git clone https://github.com/Summpot/beacon_auth.git
cd beacon_auth

# 프론트엔드 의존성 설치
pnpm install

# Rust 워크스페이스 빌드
cargo build --workspace --release
```

바이너리는 `target/release/beacon` 에 생성됩니다.
