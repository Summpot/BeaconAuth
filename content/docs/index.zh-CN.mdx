BeaconAuth 是面向 Minecraft 服务器的现代认证平台。它结合 Rust 认证服务器、React Web UI 以及多加载器 Minecraft 模组，提供安全、顺畅的登录体验。

## 核心能力

- ES256 JWT 认证与 JWKS 分发
- Web UI 登录、注册与账户管理
- OAuth 提供商（GitHub、Google、Microsoft）
- WebAuthn/Passkey 无密码登录
- Minecraft 模组 PKCE 登录流程
- Cloudflare Workers 部署选项
- 默认 SQLite，支持 serverless 友好存储
