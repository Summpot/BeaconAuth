BeaconAuth는 Minecraft 서버를 위한 현대적인 인증 플랫폼입니다. Rust 기반 인증 서버, React 웹 UI,
그리고 멀티 로더 Minecraft 모드를 결합해 안전하고 매끄러운 로그인 경험을 제공합니다.

## 주요 기능

- ES256 JWT 인증 및 JWKS 배포
- 로그인/회원가입/계정 관리를 위한 Web UI
- OAuth 제공자 (GitHub, Google, Microsoft)
- 비밀번호 없이 로그인하는 WebAuthn/패스키
- PKCE 기반 로그인 플로우를 사용하는 Minecraft 모드
- Cloudflare Workers 배포 옵션
- 기본 SQLite, 서버리스 친화적인 스토리지 옵션
