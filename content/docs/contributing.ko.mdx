description: BeaconAuth에 기여하는 방법.
---

기여는 언제나 환영합니다.

## 워크플로

1. 저장소를 포크합니다.
2. 기능 브랜치를 생성합니다 (`git checkout -b feature/amazing-feature`).
3. 변경 사항을 작업합니다.
4. 관련 테스트를 실행합니다.
5. 커밋하고 푸시합니다.
6. Pull Request를 엽니다.

## 코드 스타일

- **Rust**: `cargo fmt` 와 `cargo clippy`
- **TypeScript**: Biome (`pnpm check`)
- **Kotlin**: 저장소의 `.editorconfig` 를 따릅니다.

## 커밋 메시지

Conventional Commits를 사용합니다:

- `feat:` 새 기능
- `fix:` 버그 수정
- `docs:` 문서 변경
- `chore:` 유지보수 작업
- `test:` 테스트 추가/수정
