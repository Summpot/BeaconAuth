貢献は歓迎です。

## ワークフロー

1. リポジトリをフォークします。
2. 機能ブランチを作成します（`git checkout -b feature/amazing-feature`）。
3. 変更を加えます。
4. 関連するテストを実行します。
5. コミットして push します。
6. Pull Request を作成します。

## コードスタイル

- **Rust**: `cargo fmt` と `cargo clippy`
- **TypeScript**: Biome（`pnpm check`）
- **Kotlin**: リポジトリの `.editorconfig` に従う

## コミットメッセージ

Conventional Commits を使用します:

- `feat:` 新機能
- `fix:` バグ修正
- `docs:` ドキュメント変更
- `chore:` メンテナンス
- `test:` テスト追加/修正
