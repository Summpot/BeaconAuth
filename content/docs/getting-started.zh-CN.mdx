title: 快速开始
description: 本地或生产环境运行 BeaconAuth 的快捷方式。
---

## 使用 Docker（推荐）

```bash
# Pull the latest image
docker pull ghcr.io/summpot/beacon_auth:latest

# Run the server
docker run -d --name beaconauth \
  -p 8080:8080 \
  -v $(pwd)/data:/app/data \
  -e DATABASE_URL=sqlite:///app/data/beacon_auth.db \
  ghcr.io/summpot/beacon_auth:latest
```

服务将运行在 `http://localhost:8080`。

## 使用预编译二进制

从项目官方发布页下载适合操作系统和 CPU 的服务端压缩包，然后在本地解压。

**Linux / macOS**：

```bash
tar -xzf beaconauth-<platform>.tar.gz
chmod +x beacon
./beacon serve
```

**Windows（amd64）**：

```powershell
# Download and extract the zip file
# Run in PowerShell:
.\beacon.exe serve
```

## 从源码构建

### 前置条件

- Rust（stable）
- Node.js（LTS）
- pnpm

### 构建步骤

```bash
# Clone the repository
git clone https://github.com/Summpot/beacon_auth.git
cd beacon_auth

# Install frontend dependencies
pnpm install

# Build the Rust workspace
cargo build --workspace --release
```

二进制位于 `target/release/beacon`。
