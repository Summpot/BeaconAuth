## ローカルで起動

```bash
beacon serve
```

環境変数または CLI フラグで設定します。詳細は [設定](./configuration) を参照してください。

## データベースのセットアップ

CLI でマイグレーションとユーザー管理を行えます:

```bash
beacon migrate --database-url sqlite://./beacon_auth.db
beacon create-user --username admin --password your_secure_password
beacon list-users
beacon delete-user --username admin
```

## Docker Compose（本番）

```yaml
version: "3.8"

services:
  beaconauth:
    image: ghcr.io/summpot/beacon_auth:latest
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
    environment:
      DATABASE_URL: sqlite:///app/data/beacon_auth.db
      BIND_ADDRESS: 0.0.0.0:8080
      JWT_EXPIRATION: 7200
      BASE_URL: https://auth.example.com
      GITHUB_CLIENT_ID: ${GITHUB_CLIENT_ID}
      GITHUB_CLIENT_SECRET: ${GITHUB_CLIENT_SECRET}
      GOOGLE_CLIENT_ID: ${GOOGLE_CLIENT_ID}
      GOOGLE_CLIENT_SECRET: ${GOOGLE_CLIENT_SECRET}
      MICROSOFT_CLIENT_ID: ${MICROSOFT_CLIENT_ID}
      MICROSOFT_CLIENT_SECRET: ${MICROSOFT_CLIENT_SECRET}
      MICROSOFT_TENANT: ${MICROSOFT_TENANT}
    restart: unless-stopped
```

起動:

```bash
docker-compose up -d
```

## リバースプロキシ（Nginx）

```nginx
server {
    listen 80;
    server_name auth.example.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

HTTPS は Let’s Encrypt を利用します:

```bash
certbot --nginx -d auth.example.com
```
