BeaconAuth は Minecraft サーバー向けのモダンな認証プラットフォームです。Rust 製の認証サーバー、
React の Web UI、そして複数ローダー対応の Minecraft MOD を組み合わせて、安全でシームレスなログインを
提供します。

## 主な機能

- ES256 JWT 認証と JWKS 配布
- ログイン・登録・アカウント管理のための Web UI
- OAuth プロバイダー（GitHub / Google / Microsoft）
- WebAuthn/パスキーによるパスワードレス認証
- PKCE ベースのログインフローを備えた Minecraft MOD
- Cloudflare Workers へのデプロイ（オプション）
- 既定は SQLite（サーバーレス向けのストレージオプションも対応）
