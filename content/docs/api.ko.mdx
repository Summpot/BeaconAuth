## 기본 경로

API는 다음 경로로 제공됩니다:

- `/v1/*` (직접)
- `/api/v1/*` (`/api` 아래에 마운트된 경우)

## 핵심 엔드포인트

### 세션

- `POST /v1/login`
- `POST /v1/register`
- `POST /v1/refresh`
- `POST /v1/logout`
- `GET /v1/user/me`
- `GET /v1/user/me/avatar`
- `POST /v1/user/change-password`
- `POST /v1/user/change-username`
- `POST /v1/user/profile`

예시: `POST /v1/login`

```json
{
  "username": "player123",
  "password": "secure_password"
}
```

### Minecraft 인증 (OIDC)

Minecraft 모드는 표준 OIDC authorization-code + PKCE 흐름을 사용합니다:

- `GET /.well-known/openid-configuration` — OIDC discovery
- `GET /v1/oidc/authorize` — 인가 엔드포인트 (모드가 로그인 UI를 통해 엽니다)
- `POST /v1/oidc/complete` — SPA가 인가를 완료하고 모드로 리디렉션합니다
- `POST /v1/oidc/token` — 토큰 엔드포인트 (클라이언트 시크릿 없음, PKCE 바인딩)
- `GET /v1/oidc/userinfo` — userinfo 엔드포인트 (액세스 토큰 인가)

### Minecraft identity

Mojang 검증된 프리미엄 플레이어가 온라인 모드 바이패스로 접속할 때, 모드는 Mojang UUID가
BeaconAuth 계정에 연결되어 있는지, 그 신원을 어떻게 해결할지 확인할 수 있습니다:

- `GET /v1/minecraft/lookup?uuid=<mojangUuid>` — `X-Minecraft-Auth` 공유 비밀키
  (`MINECRAFT_LOOKUP_SECRET`)로 인증. `{ bound, identity_mode, user_subject, textures_value,
  textures_signature }`를 반환합니다.
- `GET /v1/minecraft/identity-mode` — 현재 사용자의 유효 신원 환경설정.
- `POST /v1/minecraft/identity-mode` — 현재 사용자의 환경설정(`mojang`/`legacy`)을 설정.

### OAuth

- `POST /v1/oauth/start`
- `POST /v1/oauth/link/start`
- `GET /v1/oauth/callback`

지원 프로바이더: `github`, `google`, `microsoft` (Entra ID), `minecraft` (Microsoft consumer +
Xbox, `MICROSOFT_CLIENT_ID`/`MICROSOFT_CLIENT_SECRET` 재사용). `minecraft` 프로바이더는 실제
Mojang UUID를 프로바이더 신원으로 바인딩합니다.

### 패스키 (WebAuthn)

- `POST /v1/passkey/register/start`
- `POST /v1/passkey/register/finish`
- `POST /v1/passkey/auth/start`
- `POST /v1/passkey/auth/finish`
- `POST /v1/passkey/delete`
- `GET /v1/passkey/list`
- `DELETE /v1/passkey/{id}`

### 아이덴티티

- `GET /v1/identities`
- `DELETE /v1/identities/{id}`

### 구성 및 JWKS

- `GET /v1/config`
- `GET /.well-known/jwks.json`

### 관리자

- `POST /v1/admin/migrations/up`

## 참고

- 세션 엔드포인트는 access/refresh 토큰을 위한 HttpOnly 쿠키를 설정합니다.
- JWT는 ES256으로 서명되며 JWKS로 공개됩니다.
- 일부 엔드포인트는 인증된 세션이 필요합니다.
