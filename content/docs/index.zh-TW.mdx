BeaconAuth 是一個面向 Minecraft 伺服器的現代化身分驗證平台。它結合 Rust 驗證伺服器、React Web UI，
以及支援多載入器的 Minecraft Mod，提供安全且無縫的登入體驗。

## 核心能力

- ES256 JWT 驗證與 JWKS 發佈
- 用於登入、註冊與帳戶管理的 Web UI
- OAuth 供應商（GitHub、Google、Microsoft）
- WebAuthn/通行金鑰（Passkeys）無密碼驗證
- 具 PKCE 流程的 Minecraft Mod 登入
- 可選的 Cloudflare Workers 部署
- 預設使用 SQLite，並提供更適合 serverless 的儲存選項
