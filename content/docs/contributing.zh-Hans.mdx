欢迎贡献。

## 流程

1. Fork 仓库。
2. 新建特性分支（`git checkout -b feature/amazing-feature`）。
3. 完成修改。
4. 运行相关测试。
5. 提交并推送。
6. 发起 Pull Request。

## 代码风格

- **Rust**：`cargo fmt` 与 `cargo clippy`
- **TypeScript**：Biome（`pnpm check`）
- **Kotlin**：遵循仓库 `.editorconfig`

## 提交信息

使用 conventional commits：

- `feat:` 新功能
- `fix:` Bug 修复
- `docs:` 文档变更
- `chore:` 维护性改动
- `test:` 测试增改
