歡迎各種貢獻。

## 工作流程

1. Fork 此儲存庫。
2. 建立 feature 分支（`git checkout -b feature/amazing-feature`）。
3. 進行修改。
4. 執行相關測試。
5. Commit 並 push。
6. 開啟 Pull Request。

## 程式碼風格

- **Rust**: `cargo fmt` 與 `cargo clippy`
- **TypeScript**: Biome（`pnpm check`）
- **Kotlin**: 遵循儲存庫 `.editorconfig`

## Commit 訊息

使用 conventional commits:

- `feat:` 新功能
- `fix:` Bug 修復
- `docs:` 文件變更
- `chore:` 維護工作
- `test:` 測試新增或修改
