title: BeaconAuth
description: Authentification moderne pour serveurs Minecraft avec UI web, OAuth et support mod.
---

BeaconAuth est une plateforme d’authentification moderne pour serveurs Minecraft. Elle combine un
serveur d’authentification Rust, une interface web React et un mod Minecraft multi-loader afin de
fournir des connexions sûres et transparentes.

## Capacités clés

- Authentification JWT ES256 et distribution JWKS
- Interface web pour la connexion, l’inscription et la gestion du compte
- Fournisseurs OAuth (GitHub, Google, Microsoft)
- WebAuthn/passkeys pour une authentification sans mot de passe
- Mod Minecraft avec flux de connexion basé sur PKCE
- Option de déploiement Cloudflare Workers
- SQLite par défaut, avec des options de stockage adaptées au serverless
